# AISkills

A collection of Claude Code skills, stored in `.claude/skills/`.

## Skills

| Skill | Command | Description |
|-------|---------|-------------|
| create-skill | `/create-skill [name] [description]` | Scaffolds a new skill in `.claude/skills/<name>/SKILL.md`. |

## Creating a new skill

Open this repo in Claude Code and run:

```
/create-skill my-skill-name what the skill should do
```
